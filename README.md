# MEET AND GREET Management

A polished event management landing page built as a static website app for showcasing services, community engagement, and VIP event coordination.

## Live Site

This project is designed to be published as a GitHub Pages site.

## Project Structure

- `index.html` — landing page markup
- `style.css` — theme, layout, and responsive styling
- `script.js` — small interaction for the contact form and dynamic footer year

## Local Run

Open `index.html` directly in a browser, or run a simple local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages Deployment

1. Push this repository to GitHub.
2. In the repository settings, open **Pages**.
3. Select the **Deploy from a branch** option.
4. Choose the `main` branch and `/ (root)` folder.
5. Save your settings.

Your site will be published at a GitHub Pages URL for the repository.

## Content Customization

Update the following in `index.html` to tailor the site:

- Title and branding
- Contact email and social links
- Event service descriptions
- CTA messaging
- Any project or event details

## Features

- **Responsive Design**: Mobile-first approach with smooth transitions
- **Modern UI**: Professional gradient-based design system
- **Contact Form**: Lightweight contact form with feedback
- **Accessibility**: Semantic HTML with ARIA labels
- **Performance**: Optimized for fast load times
